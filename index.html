MAIN TERMS

Database - is a physical container that holds the set of collections

Collection - is a set of MongoDB documents

Document - is the basic unit of storing data in MongoDB database.

Field - is the analogous to columns in relational databases

_id - it is a mandatory field in every MongoDB document
